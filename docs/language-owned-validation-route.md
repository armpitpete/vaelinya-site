# Owned language validation route

For the 2026-09-09 grammar reconciliation, the public site candidate is validated twice:

1. normal public repository CI, using standard zero-billed `ubuntu-latest`;
2. exact-SHA owned validation from `armpitpete/vaelinya-canon` on `[self-hosted, Linux, ARM64, oracle-ci, vaelinya]`.

The owned route checks:
- the exact site SHA;
- zero-billed CI policy;
- public language boundary;
- exact eleven-word doorway set;
- repository tests;
- Astro production build.

The public site remains a derivative publication surface. Passing either CI route grants no canon authority.
